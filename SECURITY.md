# Security policy

## Reporting a vulnerability

Do not open a public issue. Use GitHub's private reporting: **Security** tab, then **Report a
vulnerability**. Include the affected path, the steps to reproduce and the impact.

You get an answer within a few days. A fix lands on `main`; this template has no release branches.

## Scope

This repository is a template. A vulnerability in a project created from it belongs to that project.
A weakness in the template itself (the guard hooks, the CI workflows, the lint and audit rules) is in
scope here.
